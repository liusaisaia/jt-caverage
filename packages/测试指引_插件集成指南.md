# Vue3 覆盖率测试插件 - 集成测试指引

## 📦 已发布版本信息

- **@jt-coverage/vite-istanbul-tracer**: v2.0.0
- **@jt-coverage/vue3**: v1.0.0
- **registry**: https://maven.jtexpress.com.cn/nexus3/repository/npm-hosted-2/

## 🚀 快速开始

### 1. 安装依赖

在您的Vue3项目中安装插件：

```bash
# 安装核心插件
npm install @jt-coverage/vite-istanbul-tracer@2.0.0 --save-dev

# 安装Vue3适配器
npm install @jt-coverage/vue3@1.0.0 --save-dev
```

### 2. 配置 package.json

确保您的 package.json 包含正确的registry配置：

```json
{
  "name": "your-vue3-project",
  "scripts": {
    "coverage": "vue-cli-service test:unit --coverage",
    "dev:coverage": "vue-cli-service test:unit --coverage --watch"
  }
}
```

### 3. 基础集成配置

#### Option A: Vue CLI 项目 (推荐)

在 `vue.config.js` 中配置：

```javascript
const { defineConfig } = require('@vue/cli-service')
const { createVue3Adapter } = require('@jt-coverage/vue3')

module.exports = defineConfig({
  transpileDependencies: true,
  configureWebpack: {
    plugins: [
      createVue3Adapter({
        // 可选配置
        enableUI: true,        // 启用覆盖率UI
        debug: false,          // 调试模式
        autoFix: true,         // 自动修正sourcemap
        files: ['**/*.vue', '**/*.js', '**/*.ts']
      })
    ]
  }
})
```

#### Option B: 独立 Vite 项目

创建 `vite.config.js`：

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { createVue3Adapter } from '@jt-coverage/vue3'

export default defineConfig({
  plugins: [
    vue(),
    createVue3Adapter({
      mode: 'enhanced',      // enhanced | basic | auto
      enableUI: true,        // 启用覆盖率UI
      debug: false,          // 调试模式
      autoFix: true,         // 自动修正sourcemap
      sourceMap: true,       // 启用sourcemap
      files: ['**/*.vue', '**/*.js', '**/*.ts']
    })
  ],
  build: {
    sourcemap: true
  },
  test: {
    environment: 'jsdom',
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'src/main.js',
        '**/*.d.ts'
      ]
    }
  }
})
```

### 4. 测试配置

#### Jest 配置 (jest.config.js)

```javascript
module.exports = {
  preset: '@vue/cli-plugin-unit-jest/presets/typescript-and-babel',
  collectCoverageFrom: [
    'src/**/*.{js,vue,ts}',
    '!src/main.js',
    '!**/node_modules/**'
  ],
  coverageDirectory: 'coverage',
  coverageReporters: ['text', 'lcov', 'html'],
  setupFilesAfterEnv: ['<rootDir>/tests/setup.js']
}
```

#### 测试设置 (tests/setup.js)

```javascript
// 启用覆盖率收集
if (typeof window !== 'undefined') {
  window.__coverage__ = window.__coverage__ || {}
}
```

### 3. 高级配置示例

```javascript
// vue.config.js - 高级配置
const { defineConfig } = require('@vue/cli-service')
const { createVue3Adapter } = require('@jt-coverage/vue3')

module.exports = defineConfig({
  configureWebpack: {
    plugins: [
      createVue3Adapter({
        // 智能模式选择
        mode: 'auto',           // auto | enhanced | basic
        
        // Vue SFC 特殊处理
        enableVueSFC: true,
        vueTemplate: true,
        
        // SourceMap 修正
        enableSourceMap: true,
        autoFix: true,
        fixLevel: 'full',       // full | partial | minimal
        
        // 文件过滤
        files: [
          'src/**/*.vue',
          'src/**/*.js',
          'src/**/*.ts',
          '!src/main.js',
          '!src/router/**'
        ],
        
        // 调试选项
        debug: false,
        verbose: false,
        logLevel: 'info',       // error | warn | info | debug
        
        // UI 配置
        enableUI: true,
        uiTheme: 'light',       // light | dark | auto
        position: 'bottom-right' // 按钮位置
      })
    ]
  }
})
```

## 🔧 故障排除

### 常见问题

1. **覆盖率数据不准确**
   - 确保启用了 `sourcemap: true`
   - 检查文件过滤配置
   - 验证测试环境配置

2. **Vue SFC 文件覆盖率缺失**
   - 确保启用了 `enableVueSFC: true`
   - 检查Vue SFC loader配置
   - 验证模板编译设置

3. **SourceMap 修正失败**
   - 启用调试模式: `debug: true`
   - 检查sourcemap生成
   - 验证文件路径映射

### 调试模式

启用详细日志：

```javascript
createVue3Adapter({
  debug: true,
  verbose: true,
  logLevel: 'debug'
})
```

### 验证安装

运行测试并检查：

```bash
npm run test:unit -- --coverage
# 或
npm run coverage
```
